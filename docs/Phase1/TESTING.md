# Перевірка EasyStock 1.1.0

Перевірки проведено в Linux на тестових базах SQLite. Старі звіти та журнали залишаються доказами для v1.0.0.

| Набір | Підтвердження |
| --- | --- |
| `python -m pytest -q` | 77 перевірок: 63 попередні та 14 для нового складського ядра. |
| `scripts/smoke_mvp.py --with-ui` | 18 пунктів, включно з повним перезапуском і React DOM через HTTP. Нові дії у React DOM: склад, переміщення, інвентаризація, імпорт CSV, доступ до резервної копії. |
| `scripts/verify_release.py` | 8 перевірок на відтворюваний запуск без демо, оновлення, запити після перезапуску та доступ. Набори частково охоплюють однакові правила, тому їхні числа не підсумовуються. |

Авторизація перевіряється окремо від видимості кнопок: комірник не може погодити документ, менеджер не може змінювати документи, склади чи завантажити резервну копію. Два одночасні переміщення не можуть списати ті самі одиниці. Помилкова друга позиція скасовує й першу. Сторно зберігає попередні рухи; повторне проведення не змінює залишок. Підрахунок, що застарів через рух товару, відхиляється.

У перевірці резервування `.db` відновлено в окремий файл і повторно відкрито через API; залишки й документ збігаються, старі сеанси не перенесено. Міграцію перевірено на схемі v1.0.0 із наявними товарами, залишками та журналом. Збережено ідентифікатори, а передміграційна копія має стару схему.

Окремий візуальний прогін у Chromium/Firefox і запуск `.bat` у Windows з цим випуском не виконувалися в середовищі перевірки. React DOM перевіряє поведінку компонентів, а не верстку, діалог друку або сумісність браузерів.
