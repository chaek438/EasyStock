# Ініціювання та реалізація

Вихідний звіт `Original_report.pdf` містить проблему, альтернативи, стейкхолдерів, SMART-мету, метрики, межу MVP та командну угоду. Збережено авторство з наданого матеріалу: Бондаренко Сергій, група 3ІПЗс.

Фактичний результат реалізації: робочий EasyStock зі стеком, визначеним у плані. Реалізовано Must та Should, зокрема категорії, постачальників, low-stock, редагування та користувачів. Could/Won’t функції поза поточною версією.

Метрика надійності перевірена автоматизованими позитивними, негативними та конкурентними тестами. Час пошуку людиною <=30 секунд потрібно виміряти у walkthrough, а не підміняти таймінгом API.

Для завершення організаційної частини студент має створити репозиторій у власному GitHub/GitLab та дошку Backlog → To Do → In Progress → Review/Test → Done. Посилання не вигадано. Командні ролі та реальні погодження потрібно заповнити відповідно до фактичної команди. У документах не заявлено, що інтерв’ю чи сторонній review вже відбулися.
