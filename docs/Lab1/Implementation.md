# Ініціювання та реалізація

Виконав: Бондаренко Сергій

Група: 3ІПЗс. Проєкт виконував один розробник, який поєднував аналіз вимог, проєктування, реалізацію, тестування й документування.

Актуальний звіт: `Report.pdf`; редагована версія: `Report.docx`. Вихідний наданий матеріал збережено як `Original_report.pdf`.

Репозиторій уже опубліковано: https://github.com/chaek438/EasyStock. Реалізовано ядро MVP, каталог, категорії, постачальників, low-stock, редагування та керування користувачами. Обмеження функцій описані в README.

Правила надходження, списання, ролей і транзакцій перевірені автоматизованими тестами. Час пошуку людиною ≤30 секунд ще потрібно виміряти під час walkthrough.

План задач підготовлено в `docs/PROJECT_BOARD.md`; інструкція зі створення інтерактивної дошки Backlog → To Do → In Progress → Review/Test → Done міститься в `docs/GITHUB_UPDATE.md`. Фактичне посилання додається після створення дошки.

У звітах інтерв’ю позначені як змодельовані, review — як самоперевірка. Реальні інтерв’ю, незалежний review та погодження викладача не заявлені як уже виконані.
