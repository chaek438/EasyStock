# ADR-001: технологічний стек

Статус: Accepted. Джерело рішення: лабораторна №3.

Контекст: невеликий навчальний вебзастосунок із REST API, коротким циклом розробки та ролями.

Рішення: React + Vite; Python Flask; SQLAlchemy через Flask-SQLAlchemy; SQLite. Зібраний SPA обслуговується Flask у тому самому origin. Локальний запуск через Waitress.

Альтернативи: Django, Node.js, SSR-моноліт. Не обрані, щоб зберегти узгодженість із затвердженим стеком у PDF.

Наслідки: frontend і backend тестуються окремо; проксі Vite у розробці; для SQLite потрібен постійний диск. Міграція на PostgreSQL потребуватиме перевірки SQL-поведінки та міграцій схеми.
