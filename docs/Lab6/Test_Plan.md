## Версія та середовище

- Базова GitHub версія: `0eabc81b33955948421838e0a98db920a799a640`.
- Перевірений коміт коду: `6d7f8d951a23f205477960efdc3ec79648f6bb78`; локальний релізний тег: `v1.0.0`.

## Вхідні критерії

1. Чиста базова копія та зафіксований commit; 40 початкових API-тестів проходять.
2. Окрема демобаза, залежності з requirements і lockfile, готовий frontend/dist.
3. Реалізований наскрізний потік і доступні тестові облікові записи трьох ролей.

## Вихідні критерії

1. Критичні виконані сценарії Pass, новий дефект DEF-01 пройшов retest.
2. 63 API-тести, build, 18 HTTP/React DOM та 8 релізних перевірок Pass.
3. Сканування поточного індексу і доступної текстової Git-історії не має знахідок за застосованими правилами; межі сканування описані.
4. Є release notes, локальний тег, Git bundle, інструкції запуску та rollback. Немає відкритих Blocker/Critical серед зареєстрованих результатів.
5. Not run не прирівнюється до Pass. Реліз призначений для локального навчального показу; повна браузерна готовність і незалежний review не підтверджені.

## Дані та очищення

Тестовий SSD-480 починається із 17 одиниць. Базовий потік: 17 → 37 → відмова для -40 → 34. Повтор того самого +20 з тим самим ключем залишає 37. Новий ключ означає нову операцію. Після набору тимчасові бази видаляються; скрипти не приймають адресу робочого складу. Тести не запускають проти робочої бази користувача.

## Дослідницька перевірка

Маршрут власної сесії: подвійний POST → паралельний повтор → помилка запису аудиту → втрата відповіді після commit → перезапуск → повтор забороненою роллю. Знайдено DEF-01; після зміни повторний ефект не виникає в перевірених умовах. Незалежну 10–15-хвилинну сесію іншої команди не проводили; фактичну тривалість власного аналізу не хронометрували.
